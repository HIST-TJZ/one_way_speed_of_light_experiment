# 单程光速测量实验猜想 / One-Way Speed of Light Experiment

从来没有人测量过单程光速。这个仓库包含一个纯实验猜想：用运动把时间变成空间，不依赖时钟同步，首次测量单程光速。

No one has ever measured the one-way speed of light. This repository contains a pure experimental conjecture: use motion to encode time into space, bypassing clock synchronization entirely, to measure the one-way speed of light for the first time.
